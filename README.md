## features

- brutalist-inspired modern storefront ui
- full product catalog with media-rich listings powered by cloudinary
- secure auth and protected admin flows
- cart and checkout pipeline
- order tracking and management flows
- api rate limiting and hardened security headers
- strict cors + proxy-aware production setup
- ci pipeline with linting and type checks on pull requests
- scalable deployment with neon + cloud run + vercel infrastructure

---

## security

- strict cors and allowed-origin strategy
- api rate limiting for global and sensitive routes
- trust proxy configuration for cloudflare/gcp routing
- hardened http headers using helmet
- jwt-based authentication with hashed credentials
